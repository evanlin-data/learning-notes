## 建議的閱讀順序

1. 完全沒碰過 Git：先讀[《Git & GitHub 從零開始》](git/basics/)，每段都打開終端機實際做一次。
2. 做完練習後：用[《Git Guides 重點整理》](git/guides/)對照官方說法複習。
3. 會用 Git、想學 AI 開發：走[《AI Agent 學習路線》](ai-agent/)，作品會用 Git 推到 GitHub。
