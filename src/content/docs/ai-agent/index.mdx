**從會用 AI，到會自己造一個 AI Agent。**

一條為數據分析師設計的 8 週路線，每週 5–8 小時。沿途 10 站，終點是一個能放進作品集的「Campaign 分析 Agent」：你用中文問問題，它自己寫 SQL、查資料、算指標、寫報告。

<RouteMap />

點任一站就能直接跳過去。完成某一站的「動手做」清單後，那一站的圓點會填滿。

## 怎麼使用

一次走一站：讀完概念 → 看圖 → 跑程式 → 勾選「動手做」→ 做小測驗。每一站的勾選進度存在你這台電腦的瀏覽器裡。頁面最下方有「下一頁」按鈕，可以照順序走。

**適合誰：** 會一點 SQL，看得懂基本的 Python 更好，用過 ChatGPT 或 Claude 這類聊天工具。不需要機器學習背景。範例使用虛構的電商活動資料，你可以換成自己熟悉的領域。
