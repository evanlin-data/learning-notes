## 一句話定義

**AI Agent 是一個會自己決定「下一步該做什麼」，並且能動手使用工具，一直做到目標完成的 AI 程式。**

關鍵在三件事：它有**目標**（不只是回答一題），它有**工具**（能查資料庫、讀檔案、呼叫 API），它會**循環**（做一步、看結果、再決定下一步）。

:::tip[比喻]
把 AI Agent 想成一位新進的分析師同事。大腦（LLM）很聰明但剛進公司，什麼系統都還沒接觸過。你給他數據庫權限（工具），給他一本部門的 SOP 手冊（Skills），讓他有一本筆記本記事情（記憶），然後交代「幫我整理九月活動的成效」——他會自己去查、算、寫，而不是每一步都回頭問你。
:::

## AI 能力的四個階梯

職缺寫的「AI 相關能力加分」，其實橫跨好幾個層次。只停在第一階已經不夠，因為現在大家都會。

1. **會用**：用聊天介面提升效率。現在幾乎人人都會，已經不太算加分。
2. **會下指令**：寫出結構清楚、結果穩定的 Prompt，知道 AI 的限制在哪。
3. **會串接**：用程式呼叫 AI、給它工具、讓它接進真實的資料和流程。這是 Agent 的起點，也是多數求職者還沒跨過的門檻。
4. **會設計**：能判斷什麼該用 Agent、什麼不該用，能評估它答得對不對，能控制風險和成本。

:::note[實務連結]
如果你已經用 Claude Code、Cursor 這類工具做過一些自動化，其實已經踩在第 2 階和第 3 階之間。這條路線的目標是讓你穩穩站上第 3 階，並且摸到第 4 階——這也是許多 Data & AI 職缺最想看到的組合：懂數據，也懂怎麼讓 AI 安全地用數據。
:::
