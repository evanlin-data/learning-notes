## 這套能力可以帶你去哪裡

走完這條路線，你會有一個很少見的組合：懂業務指標、會寫 SQL、又能把 AI 安全地接進數據流程。這個組合可以支撐幾個方向：

- **AI 加持的數據分析師**：最直接的方向，也就是現在很多 Data & AI 職缺在找的人。你能說出自己如何用 Agent 把分析流程自動化。
- **Analytics Engineer 或 AI 應用工程師**：往技術走一步，負責替團隊建 MCP server、Skill 和自動化流程。
- **AI 產品或 BA 角色**：往業務走一步。你懂 Agent 能做什麼、不能做什麼，能把業務需求翻成可落地的規格。

現階段可以先不用碰的：從零訓練模型、深度學習的數學、fine-tuning（微調模型）、以及追著每個新框架跑。這些對 Data & AI 的入門職缺幫助有限，等你確定要往 ML 工程走再學也不遲。

## 推薦資源

- **[Claude 官方文件](https://docs.claude.com)**：API、tool use、Agent SDK 的第一手說明，型號名稱以這裡為準。
- **[Anthropic〈Building effective agents〉](https://www.anthropic.com/engineering/building-effective-agents)**：workflow 與 agent 的取捨，面試前必讀。
- **[Anthropic courses](https://github.com/anthropics/courses)**：互動式 prompt engineering 與 tool use 教學。
- **[MCP 官方網站](https://modelcontextprotocol.io)**：規格、Python SDK、官方 server 清單。
- **[DeepLearning.AI 短期課程](https://www.deeplearning.ai/short-courses/)**：有多門 Agent、MCP、RAG 的一小時入門課。
